# UI设计 · 中文说明

[返回仓库首页](./README.md)

面向 AI 编程工具的 **UI 设计 Skill 仓库**，把网页视觉参考提炼为可复用的设计原则、工作流程与交付检查项，帮助制作有明确风格的 H5、落地页和创意网站。

当前收录 **1 个 Skill：Editorial Brutalist H5（编辑式粗野主义）**。内容以设计指令与中文提示词为主；暂未提供可运行的网站模板、在线演示或效果截图。

**快速入口：** [阅读 Skill](./editorial-brutalist-h5/SKILL.md) · [复制中文提示词](./editorial-brutalist-h5/references/PROMPT.md) · [查看使用方式](#使用方式)

## 适合谁、用于什么

- **使用 AI 编程的开发者与独立创作者**：为页面生成提供具体的视觉方向和验收标准。
- **设计师与前端学习者**：研究超大字体、非对称网格、黑白对比与滚动动效如何共同构成页面。
- **品牌、作品集及活动页面的制作者**：尝试具有海报感的首屏、创意工作室网站或宣传 H5。

现有 Skill 重点服务视觉表达强烈的展示型页面。信息密集的后台、复杂表单等场景需要另行设计信息结构与交互。

### 核心能力

- **先确定视觉策略**：明确品牌、受众、页面目标、素材与 CTA，再选择风格和首屏层级。
- **建立统一的视觉语言**：约束字体尺度、配色、网格、留白、图像与主视觉层次。
- **指导前端实现**：覆盖语义化 HTML、响应式 CSS、分层布局、滚动渐显与素材呈现；可按需求使用 React 等技术。
- **提供交付检查项**：关注移动端溢出、文字可读性、键盘操作、触控目标、减少动态效果偏好和加载性能。

Skill 提供实现指导与检查标准，最终页面仍需实际运行和验证。

## 使用方式

### 方式一：直接提供给 AI 编程工具

无需先配置 Skill 自动加载，即可把现有文件作为任务上下文使用：

1. 打开 [SKILL.md](./editorial-brutalist-h5/SKILL.md)，将其内容提供给 AI，或让能读取本地文件的工具读取该文件。
2. 补充你的页面用途、受众、文案、素材、主要按钮目标和技术栈。
3. 选择一种设计方向，要求 AI 先给出视觉策略与移动端方案，再实现页面并检查效果。

可直接从下面的调用示例开始：

```text
请先阅读 editorial-brutalist-h5/SKILL.md，并按该 Skill 制作页面。

项目：个人作品集首页
受众：潜在合作方
主要目标：查看作品并联系我
设计方向：RADICAL_TYPE
技术栈：HTML / CSS / JavaScript
素材：我将提供文案和图片；缺失内容请明确标注占位。

先输出视觉策略、字体与颜色方案、首屏层级和移动端布局，
再实现页面，并检查响应式、键盘操作和减少动态效果设置。
```

如果希望直接复制一段完整的中文设计指令，使用 [PROMPT.md](./editorial-brutalist-h5/references/PROMPT.md)，补上自己的项目要求即可。

### 方式二：在支持 Skill 的工具中加载

下载仓库，或克隆到本地：

```bash
git clone https://github.com/gsakura425-ai/UI.git
```

按所用工具的 Skill 加载规则，导入整个 `editorial-brutalist-h5/` 目录，保留 `SKILL.md` 与 `references/PROMPT.md` 的相对路径。加载后，在任务中明确指定使用 `editorial-brutalist-h5`。

不同工具的安装目录与触发方式可能不同，请以其说明为准；仅克隆仓库不会自动完成安装。
