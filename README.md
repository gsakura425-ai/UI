# UI设计 · Design Skills

面向 AI 编程工具的 UI 审美与前端交互 Skill 仓库。每个参考案例独立提炼，不混合不相干的设计风格。

## 已收录

### 1. [Editorial Brutalist H5](./editorial-brutalist-h5/SKILL.md)
基于用户提供的两张创意网站截图提炼的实验性排版设计 Skill：巨型文字、黑白对比、金属 3D 主视觉、非对称网格及克制的红色强调。

- [完整 Skill](./editorial-brutalist-h5/SKILL.md)
- [中文提示词](./editorial-brutalist-h5/references/PROMPT.md)

### 2. [Immersive Storytelling H5](./immersive-storytelling-h5/SKILL.md)
参考[腾讯新闻长征90周年 H5 专题](https://h5.news.qq.com/qqfile/newsh5/long-march-90.html)的沉浸式数字叙事设计方法：章节化长页面、历史纪实质感、地图与数据可视化、滚动揭示、移动端优先。

- [完整 Skill](./immersive-storytelling-h5/SKILL.md)
- [中文提示词](./immersive-storytelling-h5/references/PROMPT.md)

## 使用方法
把对应 Skill 文件夹复制到支持 `SKILL.md` 的 AI 编程工具的 Skills 目录，并在需求中指定 Skill 名称。例如：

> 使用 immersive-storytelling-h5 Skill，为我制作一个关于校园科研成果的沉浸式 H5 专题。先输出逐屏分镜与视觉系统，再开发响应式页面。

## 说明
本仓库提炼的是可复用的设计原则，不包含参考网站的源代码或受版权保护的图片。所有生成项目应使用原创或已获授权的素材。
