# UI设计 · Design Skills

面向 AI 编程工具的 UI 设计审美 Skill 收藏仓库，重点研究高级网页视觉、实验排版和 H5 交互设计。

## 已收录

### [Editorial Brutalist H5](./editorial-brutalist-h5/SKILL.md)

从两张创意网站截图中提炼的视觉设计方法，不复制原站品牌和具体版式。

- **Monumental Chrome**：巨型衬线字体、金属 3D 主视觉、黑白高对比
- **Radical Typography**：实验性粗体排版、黑白纪实摄影、红色微强调
- 包含响应式布局、滚动动效、无障碍与性能检查规范

**使用方法：** 将 [SKILL.md](./editorial-brutalist-h5/SKILL.md) 与 [中文提示词](./editorial-brutalist-h5/references/PROMPT.md) 放在 AI 编程工具的 Skill 目录中，并在制作网站时指定使用 `editorial-brutalist-h5`。
